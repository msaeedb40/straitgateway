Install via Helm

Deploy StraitGateway into your cluster with Gateway API CRDs in minutes.

Step 1: Install Gateway API Standard CRDs 
kubectl apply --server-side -f \
  https://github.com/kubernetes-sigs/gateway-api/releases/download/v1.6.1/standard-install.yaml
Step 2: Add Helm Repository & Install StraitGateway 
helm repo add straitgateway https://msaeedb40.github.io/straitgateway/charts
helm repo update
helm install straitgateway straitgateway/straitgateway \
  --namespace straitgateway-system \
  --create-namespace

Enterprise-Grade Features

Engineered from the ground up on modern Linux eBPF primitives for unparalleled throughput and observability.

⚡

eBPF Dataplane

High-performance NetKit, TCX, and XDP kernel hooks. Direct packet forwarding with zero iptables overhead and minimum CPU consumption.

🔄

kube-proxy Replacement

Maglev consistent hashing, Direct Server Return (DSR), session affinity, and accelerated NodePort service load balancing.

🌐

Gateway API v1.6.1

Standard Kubernetes Gateway API controller supporting HTTPRoute, GRPCRoute, TCPRoute, UDPRoute, and TLSRoute.

🔗

WireGuard Transit Mesh

Hub-spoke and full-mesh inter-cluster connectivity. End-to-end kernel WireGuard encryption with 32-bit segment ID isolation.

📡

BGP + BFD Multi-Path

Dynamic route advertisement, Equal-Cost Multi-Path (ECMP) failover, and sub-second fault detection using hardware-accelerated BFD.

🔒

Zero-Trust NetworkPolicy

Identity-driven StraitNetworkPolicy engine. Strict default-deny posture with kernel LSM and socket-layer policy enforcement.
